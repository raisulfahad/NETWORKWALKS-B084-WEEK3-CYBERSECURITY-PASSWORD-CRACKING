## 📌 Project Overview
This repository documents the **Week 3 Password Cracking** practical modules completed as part of the Networkwalks Cybersecurity & Ethical Hacking internship/training program. The labs demonstrate how password-protected files store cryptographic hashes, how those hashes are extracted, and how dictionary/wordlist attacks recover weak passwords—highlighting the critical need for strong password policies and modern hashing standards.

### Completed Modules
1. **W3-PM1:** Password Cracking with John the Ripper (JTR) & Johnny GUI
2. **W3-PM2:** Password Cracking with Networkwalks Online Hash & Password Cracker Tools
